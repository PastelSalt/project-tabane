## Before you start

- Node.js installed

## Steps

### Create the app

Run create-next-app with TypeScript, ESLint and the src folder.

### Add the checks

Add the typecheck script and run lint and build once.

## Gotchas

- Generate route types before the first typecheck.

## Finished looks like

npm run dev shows the starter page and all checks pass.
